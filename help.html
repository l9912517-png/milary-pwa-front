Что это такое
PWA (Progressive Web App) — это приложение, которое работает через браузер, но выглядит как обычное приложение.

Возможности:
• установка на телефон
• отдельная иконка
• push-уведомления
• работа как приложение
Ничего скачивать из App Store или Google Play не нужно
Как установить
Установка занимает 10–20 секунд и делается через браузер.
После установки приложение появляется на рабочем столе
Android
1. Откройте сайт в Chrome 2. Нажмите ⋮ 3. Выберите "Добавить на главный экран" 4. Подтвердите
После установки открывается как обычное приложение
iPhone
1. Откройте сайт в Safari 2. Нажмите "Поделиться" 3. Выберите "На экран Домой" 4. Подтвердите
Важно: через Chrome на iPhone не работает
Компьютер
1. Откройте сайт в Chrome / Edge 2. В адресной строке нажмите "Установить"
Уведомления
При первом входе обязательно нажмите "Разрешить"
Если нажали "Запретить" — уведомления больше не спросятся

Как включить вручную:

Android → Настройки → Уведомления → включить для сайта

iPhone → Настройки → Уведомления → выбрать приложение
На iPhone уведомления работают только если приложение установлено на экран

Компьютер → значок замка в браузере → разрешить уведомления
Как пользоваться
• Файлы — готовые отчёты

• Сообщения — уведомления

• Отчёты — формирование данных
Если отчет не появился — он ещё формируется
